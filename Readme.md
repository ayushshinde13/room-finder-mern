# 🏠 RoomFinder – MERN Stack Room Booking Platform

RoomFinder is a full-stack MERN application that allows **room owners** to list rooms and **renters** to explore, request bookings, and manage rentals with a modern animated UI.

---

## 🚀 Live Demo

- **Frontend**: https://room-finder.vercel.app  
- **Backend API**: https://room-finder-api.onrender.com  

---

## ✨ Features

### 👤 Authentication
- Secure JWT-based login & signup
- Role-based access (Owner / Renter)

### 🏠 Owner Features
- Add new rooms
- View all added rooms
- Edit & delete own rooms
- Approve or reject booking requests
- View rented & booked rooms

### 🧳 Renter Features
- Explore available rooms
- Request room booking
- View booking history

### 🎨 UI & UX
- Dark mode interface
- Framer Motion animations
- Responsive design
- Modern card-based layout
